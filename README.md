# 🎙️ VoxScribe AI – Voice-to-Notes Assistant

VoxScribe AI is an AI-powered voice-to-notes assistant that converts voice recordings into structured, organized notes.

It helps users transform meetings, discussions, and voice memos into useful information such as summaries, key points, action items, deadlines, and searchable notes.

## ✨ Features

- 🎙️ Voice recording
- 📁 Audio input
- 📝 Automatic transcription
- 🧠 AI-powered summarization
- 🔑 Key point extraction
- ✅ Action item and task extraction
- 📅 Date and deadline detection
- 🗂️ Note categorization
- 🔍 Searchable note history
- 📌 Pin important notes
- 🔊 Audio playback
- 📄 TXT export
- 📕 PDF export
- 📋 Full transcript view
